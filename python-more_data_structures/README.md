# Python - More Data Structures: Set, Dictionary

Manipulation avancée des structures de données Python : ensembles (sets), dictionnaires et programmation fonctionnelle.

## Utilisation

```bash
python3 <N>-main.py
```

## Tâches

| Fichier | Fonction | Description |
| ------- | -------- | ----------- |
| `0-square_matrix_simple.py` | `square_matrix_simple(matrix)` | Retourne une nouvelle matrice avec chaque valeur au carré |
| `1-search_replace.py` | `search_replace(my_list, search, replace)` | Remplace toutes les occurrences de `search` dans la liste |
| `2-uniq_add.py` | `uniq_add(my_list)` | Additionne les entiers uniques d'une liste |
| `3-common_elements.py` | `common_elements(set_1, set_2)` | Retourne l'intersection de deux ensembles |
| `4-only_diff_elements.py` | `only_diff_elements(set_1, set_2)` | Retourne la différence symétrique de deux ensembles |
| `5-number_keys.py` | `number_keys(a_dictionary)` | Retourne le nombre de clés dans un dictionnaire |
| `6-print_sorted_dictionary.py` | `print_sorted_dictionary(a_dictionary)` | Affiche un dictionnaire trié par ordre alphabétique des clés |
| `7-update_dictionary.py` | `update_dictionary(a_dictionary, key, value)` | Ajoute ou met à jour une clé/valeur |
| `8-simple_delete.py` | `simple_delete(a_dictionary, key)` | Supprime une clé si elle existe |
| `9-multiply_by_2.py` | `multiply_by_2(a_dictionary)` | Retourne un nouveau dictionnaire avec toutes les valeurs doublées |
| `10-best_score.py` | `best_score(a_dictionary)` | Retourne la clé avec la valeur entière la plus grande |
| `11-multiply_list_map.py` | `multiply_list_map(my_list, number)` | Multiplie chaque élément avec `map()` et `lambda` |
| `12-roman_to_int.py` | `roman_to_int(roman_string)` | Convertit un nombre romain en entier |

## Concepts clés

- **Sets** : opérations d'ensemble (`&` intersection, `^` différence symétrique, `\|` union)
- **Dictionnaires** : accès, mise à jour, suppression (`del`, `.pop()`), itération (`.keys()`, `.items()`)
- **Compréhensions** de listes et de dictionnaires
- **Programmation fonctionnelle** : `map()`, `filter()`, fonctions `lambda`
- `sorted()` pour trier des clés ou valeurs
- Algorithme de conversion numérique (chiffres romains)
