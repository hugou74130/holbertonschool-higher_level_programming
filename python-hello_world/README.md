# Python - Hello, World

Introduction à Python : affichage, formatage de chaînes et manipulation de chaînes de caractères.

## Utilisation

```bash
python3 <fichier>.py
```

## Tâches

| Fichier | Description |
| ------- | ----------- |
| `2-print.py` | Affiche une phrase contenant des guillemets via `print` |
| `3-print_number.py` | Affiche un entier formaté avec f-string (spécificateur `:d`) |
| `4-print_float.py` | Affiche un float avec exactement 2 décimales (spécificateur `.2f`) |
| `5-print_string.py` | Répète une chaîne 3 fois puis affiche ses 9 premiers caractères |
| `6-concat.py` | Concatène deux variables chaînes avec f-string |
| `7-edges.py` | Extrait les 3 premiers, les 2 derniers caractères et le milieu d'une chaîne via slicing |
| `8-concat_edges.py` | Reconstruit une nouvelle chaîne par assemblage de sous-chaînes via slicing avancé |
| `9-easter_egg.py` | Affiche le Zen de Python (`import this`) |

## Concepts clés

- Fonction `print()` et chaînes avec caractères spéciaux
- **F-strings** et spécificateurs de format : `:d` (entier), `.2f` (float 2 décimales)
- **Slicing** de chaînes : `chaine[debut:fin:pas]`
- Répétition de chaîne avec l'opérateur `*`
- Import de modules de la bibliothèque standard
