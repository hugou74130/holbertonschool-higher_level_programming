# 🔥 JavaScript Warm Up

Introductory JavaScript exercises covering basic syntax and concepts.

## Files

| File | Description |
|------|-------------|
| `0-javascript_is_amazing.js` | Print a message |
| `1-multi_languages.js` | Print in multiple languages |
| `2-arguments.js` | Process CLI arguments |
| `3-value_argument.js` | Display first argument |
| `4-concat.js` | Concatenate strings |
| `5-to_integer.js` | Convert to integer |
| `6-multi_languages_loop.js` | Loop through languages |
| `7-multi_c.js` | Print C multiple times |
| `8-square.js` | Print a square |
| `9-add.js` | Add two numbers |
| `10-factorial.js` | Compute factorial |
| `11-second_biggest.js` | Find second biggest number |
| `12-object.js` | Update object property |
| `13-add.js` | Export add function |

## Usage

```bash
node 0-javascript_is_amazing.js
```
