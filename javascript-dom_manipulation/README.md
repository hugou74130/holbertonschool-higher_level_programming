# 🌐 JavaScript DOM Manipulation

Exercises for manipulating the DOM with vanilla JavaScript.

## Files

| File | Description |
|------|-------------|
| `0.html` / `0-script.js` | Change header color |
| `1.html` / `1-script.js` | Change header color on click |
| `2.html` / `2-script.js` | Add class on click |
| `3.html` / `3-script.js` | Toggle class |
| `4.html` / `4-script.js` | Add list item |
| `5.html` / `5-script.js` | Fetch and display data |
| `6.html` / `6-script.js` | POST request |
| `7.html` / `7-script.js` | Advanced fetch |
| `8.html` / `8-script.js` | Search filter |
| `9.html` / `9-script.js` | Pagination |
| `100.html` / `100-script.js` | Advanced exercises |

## Usage

Open any `.html` file in a browser:

```bash
open 0.html
```
