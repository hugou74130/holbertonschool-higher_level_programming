# 🎨 Jinja2 Templates

HTML templates for server-side rendering with Flask.

## Files

| File | Description |
|------|-------------|
| `index.html` | Homepage template |
| `about.html` | About page template |
| `contact.html` | Contact page template |
| `header.html` | Reusable header partial |
| `footer.html` | Reusable footer partial |

## Usage

These templates are rendered by Flask's `render_template()` function in the server-side rendering module.
