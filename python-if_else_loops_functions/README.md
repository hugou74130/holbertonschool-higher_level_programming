# Python - If/Else, Loops, Functions

Structures de contrôle en Python : conditionnelles, boucles et définition de fonctions.

## Utilisation

```bash
python3 <fichier>.py
```

## Tâches

| Fichier | Description |
| ------- | ----------- |
| `0-positive_or_negative.py` | Détermine si un nombre aléatoire est positif, négatif ou nul |
| `1-last_digit.py` | Analyse le dernier chiffre d'un nombre et applique des conditions dessus |
| `2-print_alphabet.py` | Affiche l'alphabet minuscule sur une ligne (boucle sur valeurs ASCII) |
| `3-print_alphabt.py` | Affiche l'alphabet sans les lettres `q` et `e` |
| `4-print_hexa.py` | Affiche les nombres de 0 à 98 en décimal et hexadécimal |
| `5-print_comb2.py` | Affiche toutes les combinaisons uniques de 2 chiffres (00 à 99) |
| `6-print_comb3.py` | Affiche toutes les combinaisons uniques de 3 chiffres différents |
| `7-islower.py` | Fonction `islower(c)` : vérifie si un caractère est une minuscule (sans `.islower()`) |
| `8-uppercase.py` | Fonction `uppercase(s)` : convertit une chaîne en majuscules (sans `.upper()`) |
| `9-print_last_digit.py` | Fonction `print_last_digit(n)` : retourne et affiche le dernier chiffre de `n` |
| `10-add.py` | Fonction `add(a, b)` : retourne la somme de deux entiers |
| `11-pow.py` | Fonction `pow(a, b)` : retourne `a` élevé à la puissance `b` |
| `12-fizzbuzz.py` | Fonction `fizzbuzz()` : algorithme classique FizzBuzz de 1 à 100 |

## Concepts clés

- `if` / `elif` / `else`
- Boucles `for` et `while` avec `range()`
- Manipulation de caractères via `ord()` et `chr()` (table ASCII)
- Opérateur modulo `%`
- Définition de fonctions avec `def` et valeur de retour `return`
- Tirage aléatoire avec `random.randint()`
